B22. Enhance the cybersecurity of a website from your community.

Perth Bridge Club, https://www.bridgewebs.com/cgi-bin/bwor/bw.cgi?pid=display_home&wd=1&club=cbdperth

The site appears to rely on dynamic content and inline scripts which is typical of an older website. So if we add a CSP then we can stop injected javascript from being executed, and make sure stored XSS dont become more severe and that third party embeds are safe and not malicious.

as the website includes News Item editors, Forms, Widgets, Uploaded content, this is important as there is meaningful XSS exposure surface.

to fix this we can add the security headers.

'
Content-Security-Policy:
default-src 'self';
script-src 'self';
object-src 'none';
base-uri 'self';
frame-ancestors 'none';
'
