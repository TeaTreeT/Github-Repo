B2. Discover 5 unique strong security implementations.
1. Multi-Factor Authentication (MFA)
Systems require a password + second factor (SMS code, authenticator app, hardware key)
Even if a password is stolen, intruders won't be able to login easy and protects against credential leaks and phishing.

3. Password hashing with salt
Passwords are never stored directly; they are hashed using secure algorithms.
Hashes are irreversible, salt prevents rainbow table attacks, makes leaked databases much harder to exploit

4. Role-Based Access Control
Users are assigned roles (admin, staff, user), and permissions are tied to roles.
It enforces least privilege principle and reduces damage if an account is compromised. It is also easier to manage than individual permissions.

6. HTTPS + TLS encryption
All data transmitted between client and server is encrypted using TLS. Used by all modern websites.
It prevents eavesdropping aka man-in-the-middle attacks and ensures data integrity while confirming the server identity via certificates.

8. Intrusion Detection Systems (IDS)
Systems monitor network/system activity and detect suspicious behaviour.
It detects attacks in real time and logs suspicious behaviour which helps incident response teams act quickly.
