RSA is an asymmetric encryption algorithm that uses a pair of keys: a public key to encrypt data and a private key to decrypt it, allowing for secure communication without sharing a secret key beforehand. RSA is used in transport layer security to securely exchange encryption keys when your browser connects to an HTTPS website.
